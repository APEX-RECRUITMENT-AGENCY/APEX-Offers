⬇ تحميل التطبيق (APK)

طريقة التثبيت

  1. اضغط زرار التحميل. لو ظهر تحذير "الملف ممكن يضر جهازك" اضغط Download anyway أو تنزيل على أي حال.
  2. افتح الملف بعد التحميل.
  3. لو طلب الموبايل، اسمح بالتثبيت من المتصفح: Settings ثم Allow from this source.
  4. لو ظهرت رسالة Play Protect اضغط Install anyway أو More details ثم Install anyway.
التحذيرات دي طبيعية لأي تطبيق مش منزّل من متجر جوجل. التطبيق بيفتح موقع الفريق الرسمي فقط.
